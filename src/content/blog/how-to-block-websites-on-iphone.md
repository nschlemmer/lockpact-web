To block a website on iPhone, open **Settings → Screen Time → Content & Privacy Restrictions → App Store, Media, Web & Games → Web Content**, choose **Limit Adult Websites**, and add the site under **Never Allow**. It's free and built in. The catch is that you can undo it yourself, so this guide also shows how to lock websites with [LockPact](/go/b-how-to-block-websites-on-iphone/), a free-to-use app where a partner has to approve before a site opens again. It's written for adults managing their own phone.

## How do you block a website on iPhone?

Use Screen Time's Web Content setting. Turn on Content & Privacy Restrictions, open Web Content, choose Limit Adult Websites, and add each address you want blocked under Never Allow. Apple's iPhone User Guide describes this as blocking specific websites by URL, and it's the setting most people mean by "block a website on Safari."

Here are the exact steps, from Apple's guide for iOS 26 (checked October 15, 2026):

1. Open **Settings** and tap **Screen Time**.
2. Tap **Content & Privacy Restrictions**, then turn on **Content & Privacy Restrictions**.
3. Tap **App Store, Media, Web, & Games**, then tap **Web Content**.
4. Select **Limit Adult Websites**.
5. Below **Never Allow**, tap **Add Website** and enter the URL of the site you want to block. Repeat for each site.

Menu labels can shift between iOS versions, so if your screen differs, open Screen Time and look for Content & Privacy Restrictions first.

## What are the limits of blocking a website this way?

Three things limit it: you list every site yourself, Apple doesn't say which browsers it covers, and whoever knows the Screen Time passcode can remove it. Safari is the browser this guide describes, so test any other browser before you rely on the block.

**You have to list each site yourself.** The setting blocks the URLs you add. There's no "block everything like this," so a site with several addresses needs each one.

**Apple doesn't say which browsers it covers.** The page describes blocking websites by URL and doesn't name a browser. The searches that lead here are about Safari, and Safari is what we describe. If you use another browser, test the block there before trusting it.

**You can undo it.** If you know the Screen Time passcode, you can open the same screen, remove the site, and carry on. That's the part that matters most, and it's the next section.

## How do you block a website so you can't undo it yourself?

You can't make it impossible, but you can move the off-switch to someone else. Have a partner set the Screen Time passcode, so removing the block means asking them, or lock the site in an app where a partner approves each unlock. Both are harder to bypass, never impossible.

**Have someone else set the Screen Time passcode.** The Web Content setting, and every other Screen Time setting, is protected by the Screen Time passcode. If a partner or friend sets it and keeps it, removing a block means asking them. ## How do you unblock a website later?

Go back to **Web Content** and remove the address from the **Never Allow** list. If a Screen Time passcode is set, you'll be asked for it first, which is why who holds the passcode matters more than the setting itself.

If you only want a site off for a few hours, add it, then remove it when the time's up, or use Downtime in the same Screen Time menu for a schedule that handles the timing for you.

## What if you're setting this up for a child?

This guide is for adults managing their own phone. Apple's guide has a separate path for a child's device: open Screen Time and tap your child's name before following the same steps. Everything above about who holds the passcode applies to that setup too.
